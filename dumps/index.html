Minidump Relay

Send a Crashpad .dmp to Sentry and get the event back. Everything happens in the browser; the DSN key is stored on this device only.

Drop a .dmp file here or click to choose · typically in logs/dumps/completed
Remembered on this device. Same key the shipped build uses — not an auth token.

The stack is only readable if debug files for that exact build are in Sentry — stable builds upload them, nightlies do not.

To check which build a dump came from: lldb --core dump.dmp, then image list mscore.
